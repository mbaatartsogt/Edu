# MindEdu — Landing сайт + Админ панел

React (Vite, Tailwind, Framer Motion) + Node.js (Express) + PostgreSQL төсөл.

```
mindedu/
├── client/                 React frontend
│   ├── public/images/      ← Зургаа энд хийнэ
│   ├── src/data/content.js ← Тогтмол текстүүд (hero, давуу тал, сэтгэгдэл)
│   ├── src/data/themes.js  ← Хөтөлбөр, салбарын картын өнгөнүүд
│   ├── src/index.css       ← Брэндийн өнгө (CSS хувьсагч)
│   ├── src/components/     ← landing/ болон ui/ компонентууд
│   └── src/pages/admin/    ← Админ панел
├── server/                 Express API
│   ├── index.js            ← API маршрутууд
│   ├── db.js               ← PostgreSQL холболт, бүртгэлийн query
│   ├── content.js          ← Хөтөлбөр, багш, салбар, тохиргооны CRUD
│   ├── seed.js             ← Анх асахад оруулах жишээ контент
│   ├── schema.sql          ← Хүснэгтийн бүтэц (сервер асахад автоматаар үүснэ)
│   └── .env.example
└── docker-compose.yml      ← Локал PostgreSQL
```

## Эхлүүлэх

Node.js 20.12+ болон PostgreSQL 13+ шаардлагатай.

```bash
docker compose up -d                 # локал PostgreSQL асаана (эсвэл өөрийн PostgreSQL-ээ ашиглана)
cp server/.env.example server/.env   # DATABASE_URL, нууц үг, JWT_SECRET-ээ солино
npm run install:all
npm run dev
```

Хүснэгтийг гараар үүсгэх шаардлагагүй: сервер асахдаа `schema.sql`-ийг ажиллуулна.
Docker байхгүй бол PostgreSQL суулгаад `createdb mindedu` хийж, `DATABASE_URL`-ээ тохируулна.

- Сайт: http://localhost:5173
- Админ: http://localhost:5173/admin  (нэр/нууц үг нь `server/.env` доторх `ADMIN_USERNAME` / `ADMIN_PASSWORD`)

## Production

👉 **Үнэгүй байршуулах алхам алхмаар заавар: [DEPLOY.md](DEPLOY.md)** (GitHub + Neon + Render, `render.yaml` бэлэн).


```bash
npm run build      # client/dist үүснэ
npm start          # Express нэг портоор (4000) сайт + API хоёуланг нь үйлчилнэ
```

### Render дээр байршуулах
1. Render → **New → PostgreSQL** үүсгэж, **Internal Database URL**-ийг хуулна.
2. **New → Web Service** → GitHub repo-гоо холбоно.
   - Build: `npm run install:all && npm run build`
   - Start: `npm start`
3. Environment хувьсагчууд: `DATABASE_URL`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `JWT_SECRET`.
   External URL ашиглах эсвэл Neon / Supabase бол `PGSSL=true` нэмнэ.

Railway, VPS (pm2) дээр мөн адил ажиллана.

### Нөөц хуулбар (backup)
```bash
pg_dump "$DATABASE_URL" > mindedu-backup.sql
psql "$DATABASE_URL" < mindedu-backup.sql   # сэргээх
```

## Эцэг эхийн хэсэг (Миний булан)

Хажуугийн цэстэй (утсан дээр ☰): **Хянах самбар**, **Хөтөлбөр сонгох**, **Сагс**, **Миний захиалгууд**, **MindPoint**.

Сагс: хэд хэдэн хөтөлбөр (эсвэл өөр өөр хүүхдэд нэг хөтөлбөр) сагсанд нэмээд, мөр бүрт хүүхдийн нэр, нас, салбараа сонгож **нийт дүнг нэг QPay QR-ээр** төлнө. Нүүр хуудаснаас нэвтрээгүй байхад ч сагсанд нэмж болно; төлөх үед нэвтрэхийг шаардана. Сагс хөтөч дээр хадгалагдах ба гарахад цэвэрлэгдэнэ.

## Эцэг эхийн бүртгэл ба төлбөр (QPay)

Эцэг эхчүүд **Нэвтрэх** товчоор утасны дугаар, нууц үгээр бүртгэл үүсгэж → хөтөлбөр, салбараа сонгож → QPay-аар төлнө.
Захиалга, орлогыг админ → **Захиалга, төлбөр** хэсгээс харна. Бэлнээр эсвэл дансаар төлсөн бол “Төлсөн болгох” товч бий.

1. Админ → **Хөтөлбөрүүд** хэсэгт хөтөлбөр бүрийн **үнийг** оруулна. Үнэгүй (0) хөтөлбөрийг онлайнаар захиалах боломжгүй.
2. QPay-тэй гэрээ байгуулж мерчант мэдээллээ авна (username, password, invoice code).
3. `server/.env` файлд:
   ```
   QPAY_MODE=live            # туршихдаа sandbox
   QPAY_USERNAME=...
   QPAY_PASSWORD=...
   QPAY_INVOICE_CODE=...
   PUBLIC_URL=https://mindedu.mn   # QPay төлбөр орсныг энэ хаягаар мэдэгдэнэ
   ```
4. Серверээ дахин асаана.

`QPAY_MODE=demo` (анхны тохиргоо) үед жинхэнэ мөнгө хөдлөхгүй, төлбөрийн хуудсанд “Төлсөн гэж тооцох (туршилт)” товч гарна.
Төлбөр орох үед QPay `PUBLIC_URL/api/payments/qpay/callback` хаяг руу мэдэгдэх ба сервер QPay-аас дахин шалгаж баталгаажуулна. Хуудас мөн 4 секунд тутам автоматаар шалгана.

## Бүртгүүлэх арга: утас (SMS код) эсвэл и-мэйл (линк)

Эцэг эх бүртгүүлэхдээ аль нэгийг сонгоно:
- **Утасны дугаар** → 6 оронтой OTP код SMS-ээр очно (5 минут хүчинтэй, 5 удаа буруу оруулбал түгжигдэнэ, 60 секунд тутамд дахин авах, цагт 5 хүртэл).
- **И-мэйл** → баталгаажуулах линк очно (доорх хэсгийг үз). Утас заавал биш.

Утсаар бүртгүүлсэн хүн нууц үгээ мартвал “Нууц үг сэргээх → Утсаар (SMS)” сонгож кодоор шинэ нууц үг тохируулна.

SMS илгээхийн тулд `server/.env` файлд SMS үйлчилгээ үзүүлэгчийнхээ API-г загвараар оруулна:
```
# GET хүсэлттэй үйлчилгээ
SMS_URL=https://api.provider.mn/send?key=XXXX&from={from}&to={to}&text={text}
SMS_FROM=MindEdu

# эсвэл POST + JSON
SMS_URL=https://api.provider.mn/v1/sms
SMS_METHOD=POST
SMS_HEADERS={"Authorization":"Bearer XXXX"}
SMS_BODY={"to":"{to976}","message":"{text}"}
```
`{to}` = 8 оронтой дугаар, `{to976}` = 976-тай, `{text}` = мессеж. SMS тохируулаагүй үед код серверийн терминал болон (туршилтын горимд) дэлгэц дээр харагдана.

## И-мэйл (бүртгэл баталгаажуулах, нууц үг сэргээх)

Эцэг эх и-мэйлээр бүртгүүлэхэд баталгаажуулах линк очно. Баталгаажуулаагүй бол нэвтрэх боломжгүй (“Линк дахин илгээх” товч бий).
“Нууц үгээ мартсан уу?” → и-мэйлээр нууц үг солих линк очно (1 цаг хүчинтэй, нэг удаагийн).

`server/.env` файлд SMTP тохируулна. Gmail жишээ:
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=manager@mindedu.mn
SMTP_PASS=xxxx xxxx xxxx xxxx     # Google бүртгэл → Security → 2-Step Verification → App passwords
MAIL_FROM="MindEdu <manager@mindedu.mn>"
APP_URL=https://mindedu.mn        # линкүүд нээгдэх хаяг (dev үед http://localhost:5173)
```
SMTP тохируулаагүй үед и-мэйл илгээгдэхгүй, линк серверийн терминал болон дэлгэц дээр (зөвхөн туршилтын горимд) харагдана.

## MindPoint (онооны систем)

- Төлбөр төлөх бүрт оноо (анхдагч: 1,000₮ тутамд 1 оноо), и-мэйл баталгаажуулахад урамшуулал (анхдагч: 50). Админ → Холбоос, холбоо барих → MindPoint хэсгээс өөрчилнө.
- Админ → **Хэрэглэгчид, оноо**: хүн бүрт оноо гараар нэмэх/хасах (олимпиад, идэвхтэй оролцоо).
- Админ → **Бэлэгнүүд**: бэлэг, шаардлагатай оноо, үлдэгдэл, зураг.
- Эцэг эх **Миний булан → MindPoint** хэсгээс бэлэг авахад `MP-XXXXXX` код үүснэ. Салбарт кодоо үзүүлэхэд админ → **Бэлэг олголт** хэсгээс “Олгосон” гэж тэмдэглэнэ. Цуцалбал оноо буцаж, үлдэгдэл сэргэнэ.
- Админ төлөгдсөн захиалгыг буцаавал тухайн захиалгын оноо хасагдана.

## Хөтөлбөр, сурагчид (төлбөрийн хугацаа)

Админ → **Хөтөлбөр, сурагчид**: хөтөлбөр бүрт бүртгэлтэй хүүхдүүд, эцэг эх, салбар, сүүлийн төлбөрийн огноо, **дараагийн төлбөр хүртэлх хугацааг progress bar**-аар харуулна.
- Төлөв: Идэвхтэй (ногоон) → Удахгүй төлөх, 7 хоног үлдсэн (шар) → Хугацаа хэтэрсэн (улаан) → Төлөөгүй (саарал).
- Дараагийн төлбөр = сүүлд төлсөн өдөр + хөтөлбөрийн **Төлбөрийн давтамж** (Хөтөлбөрүүд → Засах; сар бол 30, улирал 90, нэг удаагийн бол 0).
- **Ангийн багтаамж** оруулбал дүүргэлтийг (жишээ 12/15) харуулна.
- Эцэг эх дахин төлөхөд (сагсаар дахин захиалах) хугацаа шинээр эхэлнэ.

## Хянах самбар (хандалтын статистик)

Админ нэвтрэхэд эхлээд **Хянах самбар** нээгдэнэ (захиалга → `/admin/orders`).
- Яг одоо сайтад байгаа хүн (сүүлийн 5 минут), өнөөдрийн зочин, хуудас үзэлт.
- Зочид, хуудас үзэлт, шинэ хэрэглэгч, орлого — өмнөх ижил хугацаатай харьцуулсан хувь.
- Өдөр тутмын зочдын график, шинэ хэрэглэгч ба орлогын баганан график (хулганаа аваачихад тухайн өдрийн тоо гарна), “Хүснэгтээр харах”.
- Их үзсэн хуудсууд, хаанаас ирсэн (Facebook, Google, Instagram, шууд), төхөөрөмж (утас/компьютер/таблет).

Хэрхэн тоолдог: хуудас бүр нээгдэхэд `/api/track` руу мэдээлнэ. Зочныг хөтөч дээр хадгалсан санамсаргүй ID-гаар ялгана (IP хадгалахгүй, cookie биш).
Админ хуудас, хайлтын робот тоологдохгүй. Өдрийг `STATS_TZ` (анхдагч `Asia/Ulaanbaatar`) цагаар тоолно, `STATS_KEEP_DAYS` (анхдагч 400) хоногоос хуучин бүртгэл автоматаар устна.
Хандалт энэ хувилбарыг байршуулсан өдрөөс эхэлж тоологдоно.

## Багш нарын хэсэг (тайз)

Нүүр хуудасны “Багш нар” хэсэг: сонгосон багш голд том, тод; бусад нь хоёр талд нь ард бүдгэрч зогсоно. Багш дээр дарах, сум, гар утсан дээр гулсуулах, гарын ← → товчоор солино.
Доор нь нэр, албан тушаал, тэмдгүүд (CELTA, 8 жил…) чип хэлбэрээр, “+” товчоор танилцуулга нээгдэнэ.
Зураг дэвсгэргүй (тунгалаг PNG/WEBP) бол хүн шууд тайзан дээр зогсоно (автоматаар таньна), энгийн зураг бол нуман хүрээтэй хөрөг болно.

## Видео хичээл

Админ → **Видео хичээлүүд** → “Хичээл нэмэх”: хөтөлбөрөө сонгоод видеогоо оруулна.
- **Холбоос буулгах** — YouTube (Unlisted горимоор байршуулна), Vimeo, Google Drive эсвэл `.mp4` шууд холбоос.
- **Файл хуулах** — MP4/WEBM/MOV файл (явцын мөртэй, анхдагч 2GB хүртэл). Үргэлжлэх хугацаа автоматаар бөглөгдөнө.
- **Бүлэг** (жишээ: “Unit 1 · Greetings”) — ижил бүлгийн хичээлүүд нэг дор харагдана. Сумаар дарааллыг өөрчилнө.
- **Үнэгүй үзүүлэх** — танилцуулга хичээл, нэвтэрсэн бүх хүн үзнэ (худалдан авалтыг урамшуулна).
- Хөтөлбөр сонгоогүй (**Ерөнхий**) хичээлийг аль ч хөтөлбөрийн идэвхтэй сурагч үзнэ.

Эцэг эх → **Миний булан → Видео хичээл**: зөвхөн төлбөрөө төлсөн хөтөлбөрийнхөө хичээлийг үзнэ.
- Эрх = сүүлд төлсөн өдөр + хөтөлбөрийн **Төлбөрийн давтамж** (урьдчилж олон удаа төлбөл нэмэгдэнэ; 0 = насан туршийн).
  Хугацаа дууссанаас хойш `LESSON_GRACE_DAYS` (анхдагч 3) хоног үзэх боломжтой, дараа нь түгжигдэж “Төлбөр сунгах” товч гарна.
- Төлөөгүй хөтөлбөрийн хичээлүүд түгжээтэй харагдах ба “Худалдаж авах” дарахад сагсанд нэмэгдэнэ.
- Үзсэн/дуусгасан явц хадгалагдана, файлаар хуулсан видео сүүлд зогссон газраасаа үргэлжилнэ. Админ карт бүр дээр хэдэн хүн үзсэнийг харна.

Хамгаалалт: видео холбоосыг зөвхөн эрхтэй хүнд өгнө. Хуулсан файл 6 цагийн хугацаатай токенээр тоглогдоно (татаж авах товчгүй).
YouTube Unlisted холбоосыг эрхтэй хүн бусадтай хуваалцах боломжтой тул илүү найдвартай хамгаалалт хэрэгтэй бол Vimeo (Privacy → Hide from Vimeo + зөвхөн өөрийн домэйнд embed) эсвэл файлаар хуулна уу.

Файл хадгалах (`server/.env`):
```
VIDEO_DIR=/var/data/videos   # анхдагч: server/uploads/videos
VIDEO_MAX_MB=2048
LESSON_GRACE_DAYS=3
```
⚠️ Render/Railway-ийн диск redeploy хийхэд арилдаг. Файлаар хуулах бол **Persistent Disk** холбоод (`/var/data`) `VIDEO_DIR`-ийг түүн рүү заана, эсвэл YouTube/Vimeo холбоос ашиглана. Nginx ард байвал `client_max_body_size 2g;` нэмнэ.
Хичээлд холбогдоогүй (хадгалалгүй орхисон) файлууд 1 хоногийн дараа автоматаар устна.

## Цаг агаарын эффект

Сайт Улаанбаатарын цаг агаарыг (Open-Meteo, үнэгүй, 15 минут тутам) шалгаж: бороо орвол бороо, цас орвол цас, салхи 30+ км/ц бол салхи (навч, урсгал) харуулна. Аянгатай үед гэрэл гялсхийнэ.
Доод зүүн буланд температур болон “Эффект унтраах” товч бий. “Хөдөлгөөн багасгах” тохиргоотой төхөөрөмж дээр эффект гарахгүй.
Админ → Холбоос, холбоо барих → **Цаг агаарын эффект**: Автомат / Унтраах / Бороо / Цас / Салхи (туршиж харах). Өөр хот бол `server/.env`-д `WEATHER_LAT`, `WEATHER_LON`, `WEATHER_CITY`.

## Баярын загвар

Админ → Холбоос, холбоо барих → **Баярын загвар**: Үндсэн / Зул сар / Шинэ жил / Цагаан сар / Наадам.
Сонгоход сайтын бүх өнгө, дээд талын мэндчилгээ, чимэглэл (Зул сар — гэрлэн гирлянд, бөмбөлөг; Шинэ жил — гялалзах од; Цагаан сар — алхан хээ; Наадам — далбаа, туг) өөрчлөгдөнө. Өнгийг `client/src/index.css` доторх `[data-season]` хэсгээс засна.

## Чат-бот (автомат хариулагч)

Сайтын баруун доод буланд. AI биш, түлхүүр үгээр ажилладаг тул нэмэлт зардалгүй.
- Хөтөлбөр, салбар, утасны асуултад сайтын мэдээллээс автоматаар хариулна.
- Бусад асуултын хариуг админ → **Чат-ботын хариултууд** хэсэгт нэмнэ. Түлхүүр үгэнд үгийн язгуур (“бүртгүүл”) болон латин хэлбэр (“tulbur”) бичвэл илүү сайн таньна.
- Хариулж чадаагүй асуулт, “Бүртгүүлэх”, “Асуулт үлдээх” үед нэр, утас (бүртгэлд хүүхдийн нас) асууж аваад **Чат мессежүүд**-д хадгална.
